## 장애 복구

### 데모 중

| 증상 | 즉시 할 것 | 관객에게 할 말 |
|---|---|---|
| 지도가 안 뜬다 | 아무것도 안 해도 된다 | "지도 배경은 외부 타일이라 없을 수 있습니다. 위험 판단과 행동 안내는 그대로 보입니다" |
| 백엔드가 죽었다 | `.\make.ps1 api` 창 재실행 | 상태가 없어 즉시 복구된다 |
| 프론트가 하얗다 | 새로고침 → 안 되면 `preview` 빌드본으로 전환 | — |
| 네트워크가 끊겼다 | 그대로 진행 | "예측·판정에 외부 API 를 쓰지 않아서 네트워크 없이도 동작합니다" |
| 화면이 완전히 안 된다 | 픽스처 JSON 을 직접 보여준다 | 계약이 있다는 것 자체가 보여줄 것이다 |

### 코드

```powershell
# main 이 깨졌다 — 되돌린 뒤에 원인을 본다
git log --oneline -10
git revert <커밋해시>

# 내 로컬만 이상하다
git stash
.\make.ps1 check

# 의존성이 꼬였다
Remove-Item -Recurse -Force web\node_modules, .venv
.\make.ps1 install

# 픽스처를 잘못 고쳤다
git checkout -- contracts/fixtures/
.\make.ps1 fixtures
```

**`git reset --hard` 를 쓰지 않는다.** 남의 작업이 사라진다.

### 사고

| 상황 | 대응 |
|---|---|
| API 키를 커밋했다 (push 전) | `git reset --soft HEAD~1` 후 다시 커밋 |
| API 키를 push 했다 | **먼저 서울시 포털에서 키를 재발급한다.** 이력 정리는 그 다음 |
| 대용량 파일을 push 했다 | `git rm --cached <파일>` + `.gitignore` 추가 |
