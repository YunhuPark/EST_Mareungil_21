### 재생성 스크립트는 이 저장소에 없다

다이어그램의 편집 원본은 `scripts/render_*.ps1` 이지만 **공유 저장소에 포함하지 않았다.**
11시간 안에 다이어그램을 다시 그릴 일이 없다고 판단해서다. PNG 는 완성본이므로
그대로 쓰고, **PNG 를 직접 고치지 않는다.** 수정이 필요하면 저장소 주인에게 요청한다.

같은 이유로 `scripts/probe_minute_resolution.py`(분단위 확장계획의 수치 재생성)도
포함하지 않았다. 해당 계획은 MVP 범위 밖이다.

PNG에서 하수 데이터는 “2022 과거 원본 · 명목상 1분 간격 · 통신두절 누락”으로 표현한다. 이는 현재 시점의 1분 관측을 뜻하지 않는다.

## 상태 주의

설계서와 요구사항 정의서는 **목표 설계**다. 문서에 적혀 있다는 이유로 구현 완료로 읽지 않는다.

2026-08-15 부트스트랩으로 `SafeRoute`·`AssessResponse`·공식정보 스키마와 `services/`·`api/`·`web/`·`tests/` 가 생겼지만, **판단 엔진과 경로 엔진 본체는 아직 없다.** 지금 화면에 보이는 행동·경로는 픽스처 값이다.

무엇이 구현됐고 무엇이 STUB 인지는 [저장소 감사](./REPOSITORY_AUDIT.md) 6절에 표로 있다. 그 표를 정본으로 본다.
