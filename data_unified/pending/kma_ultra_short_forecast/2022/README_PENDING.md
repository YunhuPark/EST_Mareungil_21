# 미수집: 2022년 기상청 초단기예보

상태: 다운로드 필요

## 받을 자료

- 출처: 기상자료개방포털 초단기예보 파일셋
- 링크: https://data.kma.go.kr/data/rmt/rmtList.do?code=410&pgmNo=571
- 우선기간: 2022-08-01~2022-08-31
- 확대기간: 2022-01-01~2022-12-31
- 공간: 강남구·서초구 및 인접 동네예보 격자
- 요소: 강수량
- 함께 받을 것: 격자번호(nx, ny)-위경도 변환자료, 코드 설명서

## 주의사항

- 파일 발표시각이 UTC이면 KST로 9시간 변환한다.
- 발표시각과 예측대상시각을 별도 컬럼으로 보존한다.
- 실제 관측 이후에 발표된 예보가 과거 학습행에 들어가지 않도록 발행시각 기준으로 결합한다.
- KMA API 인증키는 발급 완료 상태이나 실제 키 값은 저장하지 않았다. 연장 신청이 필요하다.
